# TFT Moderator Onboarding

Training and reference portal for The Forbidden Trove moderation team.

## Live Website

https://ri-el.github.io/tft-moderator-onboarding/

## Features

- 12 moderator onboarding sections
- Moderation principles and workflows
- Discord-style scenario examples
- Searchable moderator command reference
- Responsive desktop and mobile design

## Deployment

Hosted with GitHub Pages and automatically deployed from the `main` branch.
